# Divine Art Showcase

Build a complete, modern, premium e-commerce frontend website for a Pakistani handcrafted art and calligraphy brand called:

MEER DIVINE ART

IMPORTANT: FRONTEND ONLY

This project is only the frontend for now.

Do NOT build:
- Backend
- Database
- Authentication
- Admin panel
- Payment gateway
- CMS
- Real checkout
- API integrations

Use mock/static product data and frontend state only.

==================================================
VERY IMPORTANT: IMAGE PLACEHOLDER RULE
==================================================

DO NOT generate any AI images.

DO NOT use image generation tools.

DO NOT create AI-generated artwork.

DO NOT use random online images or stock photos.

DO NOT use external image URLs.

For EVERY image location, use a clean visual IMAGE PLACEHOLDER instead.

The placeholders should look intentional and premium, not like broken images.

Create reusable components such as:

<ImagePlaceholder />

The placeholder should:
- Match the Meer Divine Art color palette
- Have a warm beige / ivory background
- Have a subtle border
- Include a small image icon
- Optionally display text such as:
  "Product Image"
  "Hero Image"
  "Collection Image"
  "Gallery Image"

For product cards, use different placeholder blocks with different aspect ratios where appropriate.

For example:

Hero:
[ Large Hero Image Placeholder ]

Product card:
[ Product Image Placeholder ]

Category:
[ Collection Image Placeholder ]

Product detail:
[ Large Product Image Placeholder ]
[ Thumbnail Placeholder ]
[ Thumbnail Placeholder ]

Make the placeholders visually attractive so the website still looks like a polished real website.

IMPORTANT:
Keep the image components easy to replace later with actual images.

Do NOT leave broken image icons.
